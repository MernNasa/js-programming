# Sliding Window Technique

let arr = [2, 1, 5, 1, 3, 2];

3. Find the minimum sum of K consecutive elements

let arr = [4, 2, 1, 7, 3, 2];

4. Find the average of every K consecutive elements

let arr = [2, 4, 6, 8, 10];

let k = 3;

let arr = [1, 12, -5, -6, 50, 3];

out: 12.75

The window [12, -5, -6, 50] has sum 51, and its average is 12.75.

# Set in JavaScript

A Set is a built-in JavaScript object that stores unique values. It does not store duplicate values.

Remember: An array can contain duplicate values, but a Set keeps only unique values. A Set also preserves the insertion order of its unique values.

## How Do We Create a Set?

There are three common ways to start working with a Set.

1. Create an empty Set

let set = new Set();

2. Create a Set from an array

let set = new Set([1, 2, 3, 2, 1]);

3. Create a Set from a string

let set = new Set("banana");

## Important Set Methods

1. add()

Adds a value to the Set. If that value already exists, nothing is duplicated.

2. has()

Checks whether a value exists. It returns true or false.

3. delete()

Removes a specific value from the Set.

4. clear()

Removes every value from the Set.

5. size

Returns the number of unique values. Note that size is a property, not a method.

## Other Useful Ways to Work with a Set

let set = new Set([10, 20, 30]);

for (let value of set) {

console.log(value);

}

forEach() — execute a callback for each value

let set = new Set(["A", "B", "C"]);

set.forEach(function(value) {

console.log(value);

});

# Sorting Algorithms in JavaScript

## 1. What Is Sorting?

Sorting is the process of arranging elements in a particular order.

There are two common types of sorting:

- ****Ascending Order:**** Arranging elements from smallest to largest.

- ****Descending Order:**** Arranging elements from largest to smallest.

****Example:****

```javascript

let arr = [40, 10, 30, 20, 50];

// Ascending Order

// [10, 20, 30, 40, 50]

// Descending Order

// [50, 40, 30, 20, 10]

```

## 2. Types of Sorting Algorithms

The important sorting algorithms are:

1. Bubble Sort

2. Selection Sort

3. Insertion Sort

4. Merge Sort

5. Quick Sort

6. Heap Sort

---

## 3. Bubble Sort

### What Is Bubble Sort?

Bubble Sort is a sorting algorithm that compares adjacent elements and swaps them if they are in the wrong order.

After each pass, the largest unsorted element moves to its correct position at the end of the array.

### Algorithm

1. Start from the first element.

2. Compare the current element with the next element.

3. If the current element is greater than the next element, swap them.

4. Continue until the end of the unsorted portion.

5. Repeat until the array is sorted.

### Example

Input:

```javascript

[5, 3, 8, 1]

```

****Pass 1:****

- Compare 5 and 3 → Swap.

- Compare 5 and 8 → No swap.

- Compare 8 and 1 → Swap.

Array after Pass 1:

```javascript

[3, 5, 1, 8]

```

****Pass 2:****

- Compare 3 and 5 → No swap.

- Compare 5 and 1 → Swap.

Array after Pass 2:

```javascript

[3, 1, 5, 8]

```

****Pass 3:****

- Compare 3 and 1 → Swap.

Final Output:

```javascript

[1, 3, 5, 8]

```

### JavaScript Program

```javascript

let arr = [5, 3, 8, 1];

for (let i = 0; i < arr.length - 1; i++) {

for (let j = 0; j < arr.length - 1 - i; j++) {

if (arr[j] > arr[j + 1]) {

let temp = arr[j];

arr[j] = arr[j + 1];

arr[j + 1] = temp;

}

}

}

console.log(arr);

// [1, 3, 5, 8]

```

### Complexity

- Best Case: O(n) with an early-exit optimization.

- Average Case: O(n²).

- Worst Case: O(n²).

- Space Complexity: O(1).

- Stable: Yes.

### Advantages

- Easy to understand and implement.

- Works well for small arrays used in learning.

- Requires very little additional memory.

### Disadvantages

- Inefficient for large arrays.

- Performs many comparisons and swaps.

---

## 4. Selection Sort

### What Is Selection Sort?

Selection Sort repeatedly finds the smallest element from the unsorted portion and places it at the beginning of that portion.

### Algorithm

1. Assume the first unsorted element is the minimum.

2. Compare it with the remaining elements.

3. Find the index of the smallest element.

4. Swap the smallest element with the first unsorted element.

5. Repeat until the array is sorted.

### Example

Input:

```javascript

[64, 25, 12, 22, 11]

```

****Pass 1:**** The smallest element is 11.

```javascript

[11, 25, 12, 22, 64]

```

****Pass 2:**** The smallest remaining element is 12.

```javascript

[11, 12, 25, 22, 64]

```

****Pass 3:**** The smallest remaining element is 22.

```javascript

[11, 12, 22, 25, 64]

```

Final Output:

```javascript

[11, 12, 22, 25, 64]

```

### JavaScript Program

```javascript

let arr = [64, 25, 12, 22, 11];

for (let i = 0; i < arr.length - 1; i++) {

let minIndex = i;

for (let j = i + 1; j < arr.length; j++) {

if (arr[j] < arr[minIndex]) {

minIndex = j;

}

}

let temp = arr[i];

arr[i] = arr[minIndex];

arr[minIndex] = temp;

}

console.log(arr);

// [11, 12, 22, 25, 64]

```

### Complexity

- Best Case: O(n²).

- Average Case: O(n²).

- Worst Case: O(n²).

- Space Complexity: O(1).

- Stable: No, in its standard implementation.

### Advantages

- Easy to understand.

- Performs at most O(n) swaps.

- Uses constant additional memory.

### Disadvantages

- Performs O(n²) comparisons even when the array is already sorted.

- Not suitable for large arrays.

---

## 5. Insertion Sort

### What Is Insertion Sort?

Insertion Sort takes one element at a time and inserts it into the correct position within the already-sorted portion of the array.

It works similarly to arranging playing cards in your hand.

### Algorithm

1. Consider the first element sorted.

2. Take the next element as the key.

3. Compare the key with elements on its left.

4. Shift larger elements one position to the right.

5. Insert the key into the correct position.

6. Repeat until the array is sorted.

### Example

Input:

```javascript

[5, 3, 4, 1, 2]

```

After inserting 3:

```javascript

[3, 5, 4, 1, 2]

```

After inserting 4:

```javascript

[3, 4, 5, 1, 2]

```

After inserting 1:

```javascript

[1, 3, 4, 5, 2]

```

Final Output:

```javascript

[1, 2, 3, 4, 5]

```

### JavaScript Program

```javascript

let arr = [5, 3, 4, 1, 2];

for (let i = 1; i < arr.length; i++) {

let key = arr[i];

let j = i - 1;

while (j >= 0 && arr[j] > key) {

arr[j + 1] = arr[j];

j--;

}

arr[j + 1] = key;

}

console.log(arr);

// [1, 2, 3, 4, 5]

```

### Complexity

- Best Case: O(n).

- Average Case: O(n²).

- Worst Case: O(n²).

- Space Complexity: O(1).

- Stable: Yes.

### Advantages

- Simple to implement.

- Efficient for small arrays.

- Performs well when the array is already sorted or nearly sorted.

### Disadvantages

- Inefficient for large, randomly ordered arrays.

---

## 6. Merge Sort

### What Is Merge Sort?

Merge Sort is a divide-and-conquer sorting algorithm.

It divides an array into smaller parts, sorts those parts recursively, and merges them into one sorted array.

### Algorithm

1. Divide the array into two halves.

2. Continue dividing until each part contains one element.

3. Merge the smaller arrays in sorted order.

4. Continue merging until one sorted array remains.

### Example

Input:

```javascript

[38, 27, 43, 3]

```

Divide:

```text

[38, 27]    [43, 3]

[38] [27]   [43] [3]

```

Merge in sorted order:

```text

[27, 38]    [3, 43]

[3, 27, 38, 43]

```

### JavaScript Program

```javascript

function mergeSort(arr) {

if (arr.length <= 1) {

return arr;

}

let mid = Math.floor(arr.length / 2);

let left = mergeSort(arr.slice(0, mid));

let right = mergeSort(arr.slice(mid));

return merge(left, right);

}

function merge(left, right) {

let result = [];

let i = 0;

let j = 0;

while (i < left.length && j < right.length) {

if (left[i] <= right[j]) {

result.push(left[i]);

i++;

} else {

result.push(right[j]);

j++;

}

}

return result.concat(

left.slice(i),

right.slice(j)

);

}

console.log(mergeSort([38, 27, 43, 3, 9, 82, 10]));

// [3, 9, 10, 27, 38, 43, 82]

```

### Complexity

- Best Case: O(n log n).

- Average Case: O(n log n).

- Worst Case: O(n log n).

- Auxiliary Space: O(n).

- Stable: Yes, for this implementation.

### Advantages

- Provides predictable O(n log n) time complexity.

- Suitable for large datasets.

- Stable when implemented appropriately.

### Disadvantages

- Requires additional memory for merging.

- Recursive calls introduce overhead.

## 7. Quick Sort

### What Is Quick Sort?

Quick Sort is a divide-and-conquer algorithm that selects a pivot element and partitions the other elements into groups based on their relationship to the pivot.

The smaller elements are placed on one side, and the larger elements are placed on the other side.

### Algorithm

1. Select a pivot element.

2. Partition the other elements into smaller and larger groups.

3. Apply Quick Sort recursively to each group.

4. Combine the sorted groups with the pivot.

### Example

Input:

```javascript

[10, 7, 8, 9, 1, 5]

```

Choose 5 as the pivot.

```text

Smaller elements: [1]

Pivot:             5

Larger elements:  [10, 7, 8, 9]

```

After recursively sorting the groups:

```javascript

[1, 5, 7, 8, 9, 10]

```

### JavaScript Program

```javascript

function quickSort(arr) {

if (arr.length <= 1) {

return arr;

}

let pivot = arr[arr.length - 1];

let left = [];

let right = [];

for (let i = 0; i < arr.length - 1; i++) {

if (arr[i] <= pivot) {

left.push(arr[i]);

} else {

right.push(arr[i]);

}

}

return [

...quickSort(left),

pivot,

...quickSort(right)

];

}

console.log(quickSort([10, 7, 8, 9, 1, 5]));

// [1, 5, 7, 8, 9, 10]

```

### Complexity

- Best Case: O(n log n).

- Average Case: O(n log n).

- Worst Case: O(n²).

- Space Complexity: Depends on recursion depth and additional arrays.

- Stable: No, in general.

### Advantages

- Usually performs well in practice.

- Can be implemented in place to reduce additional memory usage.

- Has good average time complexity.

### Disadvantages

- Poor pivot selection can lead to O(n²) time complexity.

- The implementation above creates additional arrays.

- Standard Quick Sort is not stable.

---

## 8. Heap Sort

### What Is Heap Sort?

Heap Sort uses a binary heap data structure to sort elements.

For ascending order, it commonly builds a max heap, where the largest element is at the root.

### Algorithm

1. Build a max heap from the array.

2. Swap the root with the last element.

3. Reduce the heap size.

4. Restore the max-heap property.

5. Repeat until the array is sorted.

### Complexity

- Best Case: O(n log n).

- Average Case: O(n log n).

- Worst Case: O(n log n).

- Auxiliary Space: O(1) for an iterative in-place implementation.

- Stable: No.

### Advantages

- Guarantees O(n log n) time complexity.

- Can sort in place.

- Does not require a separate array proportional to the input size.

### Disadvantages

- More difficult to understand than Bubble Sort or Selection Sort.

- Often has poorer practical cache performance than well-implemented Quick Sort.

## 10. Built-in Sorting in JavaScript

JavaScript provides the `sort()` method to sort array elements.

By default, `sort()` converts elements to strings and compares their UTF-16 code units. For numerical sorting, provide a comparison function.

### Ascending Order

```javascript

let arr = [40, 10, 30, 20, 5];

arr.sort((a, b) => a - b);

console.log(arr);

// [5, 10, 20, 30, 40]

```

### Descending Order

```javascript

let arr = [40, 10, 30, 20, 5];

arr.sort((a, b) => b - a);

console.log(arr);

// [40, 30, 20, 10, 5]

```

### Sorting Strings

```javascript

let names = ["Ravi", "Amit", "Kiran", "Balu"];

names.sort();

console.log(names);

// ["Amit", "Balu", "Kiran", "Ravi"]

```

### Sorting Objects by Marks

```javascript

let students = [

{ name: "Ravi", marks: 75 },

{ name: "Amit", marks: 90 },

{ name: "Kiran", marks: 60 }

];

students.sort((a, b) => a.marks - b.marks);

console.log(students);

```

The students are sorted by marks in ascending order.

### Important Points About `sort()`

- `sort()` modifies the original array.

- A numerical comparator is needed for correct numerical sorting.

- JavaScript's built-in array sort is stable in modern ECMAScript implementations.

- The exact algorithm used by the JavaScript engine is implementation-dependent.

To preserve the original array, use `toSorted()` in environments that support it, or sort a copy:

```javascript

let arr = [30, 10, 20];

let sortedArr = [...arr].sort((a, b) => a - b);

console.log(sortedArr); // [10, 20, 30]

console.log(arr);       // [30, 10, 20]

```

# What is a searching algorithm?
Definition: A searching algorithm is a step-by-step procedure used to find a particular element (called the target or key) in a collection of data, such as an array.

# Types of searching algorithms
1. Linear Search
Checks elements one by one until the target is found or the collection ends.
2. Binary Search
Repeatedly divides a sorted search range into two halves.

# Linear Search
Definition
Linear Search is a searching algorithm that checks each element in a collection sequentially, starting from the first element, until the target is found or all elements have been checked.
It is also called Sequential Search.

# Algorithm steps
1. Start from index 0.
2. Compare the current element with the target.
3. If they are equal, return the current index.
4. Otherwise, move to the next element.
5. If the loop finishes without finding the target, return -1.

# code 


```javascript


function linearSearch(arr, target) {
    for (let i = 0; i < arr.length; i++) {
        if (arr[i] === target) {
            return i;
        }
    }

    return -1;
}

let arr = [10, 25, 30, 45, 50];

console.log(linearSearch(arr, 30)); // 2
console.log(linearSearch(arr, 45)); // 3
console.log(linearSearch(arr, 99)); // -1


```

# Binary Search
Definition
Binary Search is a searching algorithm that finds a target element in a sorted array by repeatedly dividing the current search range into two halves.

Instead of checking every element, it eliminates half of the remaining search space after each comparison.

Important rule: Binary Search requires the array to be sorted in ascending or descending order. The code below assumes ascending order.

# Algorithm steps
1. Initialize left = 0 and right = arr.length - 1.
2. While left <= right, calculate the middle index.
3. If the middle element equals the target, return mid.
4. If the target is greater than the middle element, set left = mid + 1.
5. If the target is smaller than the middle element, set right = mid - 1.
6. If the search range becomes empty, return -1.

``` javascript
     
function binarySearch(arr, target) {
    let left = 0;
    let right = arr.length - 1;

    while (left <= right) {
        let mid = Math.floor((left + right) / 2);

        if (arr[mid] === target) {
            return mid;
        }

        if (target > arr[mid]) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return -1;
}

let arr = [10, 20, 30, 40, 50, 60, 70];

console.log(binarySearch(arr, 60)); // 5
console.log(binarySearch(arr, 20)); // 1
console.log(binarySearch(arr, 99)); // -1

```
